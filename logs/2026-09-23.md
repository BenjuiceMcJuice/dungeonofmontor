# 2026-09-23 — Platformer mode spec (Montor's Descent)

## What

Specced a new version of the game: **Montor's Descent**, a room-by-room side-view platformer that keeps the same mechanics, content and sprites as The Crawl. Design only — no code yet.

Spec: `dom-app/docs/platformer_mode_spec.md`

## Key decisions

- **Third Tavern mode**, alongside Montor's Crawl (turn-based) and Montor's Tale (narrative). Not a fork — reads the same `src/data/*.json` and calls the same `lib/` engine functions.
- **One chamber = one screen.** The existing 4x4 zone maze (`generateMaze`/`generateZone`) is reused; maze connections become side doors (L/R), ladders/hatches (up) and drop holes (down).
- **Hidden dice.** Physical hit detection decides *if* you connect; the existing d20 4-tier resolver decides *how well* (crit/hit/glancing/miss), with a +4 "connected" bonus. Traps, searches, crits, loot all still roll.
- **Stats keep their Crawl meaning** plus a movement feel (AGI = speed/attack speed/i-frames, END = stamina + weight affects jump, PER = reveals secrets, etc.).
- **"Montor tick"** — a global 1 s tick replaces the turn for conditions, regen and bomb fuses, so `tickConditions` and reactions work unchanged.
- **Weapon classes become movesets** (dagger combo, spear reach/pogo, mace overhead stagger, axe wide arc, sword balanced, fists grab/throw).
- **Enemy AI behaviours** (flee, howl, heal ally, eat corpse, sacrifice, slime coat, spawn) mapped to movement patterns per archetype.
- **Art:** existing sprite grids reused at native size with tier colour swaps; new art (knight animation frames, 16 px tiles, side-view doors) drawn in the same K/C/S grid format.
- **Tech:** plain canvas 2D, fixed-timestep loop in `src/platformer/`, React only for overlays (inventory, merchant, gifts, StatPicker reused). No game engine dependency.
- 5-phase build plan (P0 feel prototype -> P4 polish) added to DEVLOG.

## Example room mockup

Drew an example platformer room: **The Potting Shed** (Garden, chamber B2), in `dom-app/docs/platformer_room_mockup.html` (open in a browser).

- Uses the **real sprite grids** from `lib/sprites.js` (knight, Dust Rat, Slate Slug, bat, rat corpse, junk piles x2, chest, trap, garden gate doors, WET icon). They were extracted with a node script and embedded, so the file is standalone.
- Tiles (stone blocks, dirt/grass floor, puddle, one-way plank, ladder, ceiling hatch) are placeholders in the same black-outline flat style using the garden `doorThemes` colours.
- 14 numbered callouts: open door in, sealed door, knight mid-swing, rat, corpse, puddle (WET), one-way plank, junk heap, ladder/hatch (up exit), bat, slug, chest, PER-spotted trap, junk mound (possible terminal).
- Mechanics explainer on the same page: a five-step run through the room, a working "hidden d20" swing demo using the Crawl's numbers (sword d6, STR +1, +4 connected bonus, Dust Rat 8 HP / DEF 5), a Montor tick strip (BLEED + WET + CHARGED -> CONDUCTANCE), stats-in-the-room table, zone map position, weapon movesets.
- Noted in the mockup that the knight still needs side-on animation frames and the doors need side-view versions.

## Design options — making it its own game

User feedback on the v0.1 spec: too directly a port of the Crawl mechanics; wants it more fun, with the junk lying around used as a puzzle.

Wrote `dom-app/docs/platformer_design_options.md`:
- Foundation: every named junk item becomes a physical object with weight / shape / material / one behaviour verb. Player verbs: pick up, carry, drop, stack, throw, push, kick, break.
- Nine directions: A stack-to-reach, B contraptions (3 parts -> tool), C wear-the-house (fight with whatever you hold, it breaks), D cleaning (bins + tidy/messy exits), E dig (piles as layered heaps with silhouettes), F chain-reaction rooms, G memory (rebuild the 6 Treasures from fragments), H greed (unlimited sack, creaking floors), I co-op junk.
- Comparison table, recommended combination (C + E + D core, H scoring, G floor goal, B/F later for boss rooms), the Potting Shed re-described under the new rules, 6-step prototype order, open questions.
- Stats collapse to STR / AGI / PER as felt effects; d20 and most conditions dropped for this mode (6 kept as room effects).

Files: `dom-app/docs/platformer_design_options.md` (new), `INDEX.md`, `platformer_mode_spec.md` (link), `DEVLOG.md`.
