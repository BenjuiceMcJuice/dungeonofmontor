# 2026-09-24 — Montor's Descent spec v1

Decisions from the user on the design options: **snap-to-grid**, **simple stats**, **fixed Montor responses**. Wrote the v1 spec on that basis.

Spec: `dom-app/docs/platformer_descent_spec.md`

## What's in it

- **Grid:** 20x12 tiles of 16px; everything snaps; knight 1x2, jumps 3 high / 4 wide. Tile types incl. bins, plinth, hole, breakable floorboard.
- **Stats:** MIGHT / NIMBLE / EYE, 1-5, start 2/2/2. Raised only by eating Montor's food from piles (existing consumable junk). Fixed 6 hearts. No XP.
- **Junk objects:** every `junk.json` id gets size / weight / material / use / hits in a new `descent-objects.json`. Verbs: pick up, use (swing/throw/whip/block), put down (stacks), wear, sack, push. Stack stability rules; heavy crushes light.
- **Combat:** no dice. Damage from the object. Five material rules replace the conditions system: wood/paper burns, metal in water zaps, ceramic shatters to neighbours, organic attracts rats, heavy drop crushes.
- **Piles:** 1-4 layers, spill a layer per hit, EYE previews silhouettes, one trap layer per pile guards the best layer, one mound per floor has a treasure fragment at the bottom, burn to clear fast (destroys organic/paper).
- **Exits:** tidy door (fill bin quota: wood / metal / Montor's) leads to the better room; trash exit always open, mood -1. Mess meter per room.
- **Sack:** unlimited, weight tiers change jump, walk, floorboards (creak → fall to the room below), rats steal at 16+. Emptied only at the safe room: sell / Dump / give to Montor.
- **Treasures:** 3 fragments per floor in mound bottoms, crack when dropped, assemble on the plinth → existing `montorReaction` line + simplified one-effect Gifts (Petal vine bridge, Stone heavy-as-medium, Bile rot puddle, Blood heal per 5 hits, Ember lit wood, Void weightless 10 s). Banked Gifts shared with the Crawl.
- **Montor:** `descent-montor.json`, ~17 events, 3-6 lines each, reuses `montorWhispers` for idle. Mood -10..+10 from tidy/trash/break/burn/give; two endings.
- **Enemies:** 12 archetypes, each one move rule + one junk rule (rat drags from bins, mimic eats thrown objects, shade swaps objects, moth eats cloth...). HP 1-5 by tier.
- **Floors:** one new rule per floor (tall rooms, water, fragile, fire+forge, dark, no bins).
- **Code layout:** `src/descent/` (engine, grid, objects, player, piles, bins, enemies, montor, render, input, save) + 4 data files; reuses sprites, generateMaze, junk.json, DungeonMap, Gift overlay, characterSave.
- **Build plan P0-P6**, each with the question it answers.
